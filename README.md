# Arduino Control System

This is a personal learning project I built to get hands-on experience with control logic, relays, inputs/outputs, permissives, and interlocks.

The system uses an Arduino with physical pushbuttons, switches, LEDs, and a relay module to simulate basic control system behavior.

## Current Features

- Start/Stop control
- E-stop input
- Master permissive
- Individual relay control
- Status indicator LEDs
- Permissive and interlock logic
- Latching controls
- Button edge detection

## What I'm Learning

- Understanding digital inputs and outputs
- Following signal flow
- Relay and control logic
- Building permissives and interlocks
- Reading and troubleshooting control logic
- Using code to control physical devices
- Troubleshooting unexpected system behavior

## Project Goal

The goal is to continue expanding the system as I learn more about industrial controls and PLC systems.
